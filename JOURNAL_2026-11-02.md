   ```bash
   python tools/prepare_submission.py examples/final/final_submission.json --output output/final/final_submission.json
   ```

   - Expect `PENDING_SELECTION`, later `PENDING_REVIEW`. **Never resubmit while pending.**
6. **Record it.** Add a journal entry with the submission id and status, the commit the
